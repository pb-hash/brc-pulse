BRC Pulse changes
=================
Version numbers: last number for fixes and wording, middle number for new
features, first number for changes to the page's data sources or security
model. Test builds carry "-test.N" and are never published. The build code
comes from the page's code alone, so the hourly data never changes it.

1.1.0 (in testing)
  - Check a stamp: verify BRC Seal postmark receipts against the chain, with
    an optional Lock ID and a drand "made after" beacon checked in the page.
  - The block 100,000 giveaway: address-only entries sealed in the page and
    dropped in the BRC Mailbox, the prize pool, the published lists and their
    fingerprints, and the drand draw, all checked in the page.
  - Messages signed on the chain in BRC Seal, and mailbox links, are checked
    in Check a stamp. A copy locked by another address is refused.
  - Is this BRC Works file genuine? A file is fingerprinted in the page and
    matched to a release signed on the chain by the BRC Works release address.
  - BRC Works addresses, with live balances, on the Stamps view. Addresses
    imitating any named address are marked as look-alikes.
  - The version and build code are shown in the footer.

1.0.0
  - Live network stats, history since launch, My BRC address pages.
