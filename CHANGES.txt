BRC Pulse changes
=================
Version numbers: last number for fixes and wording, middle number for new
features, first number for changes to the page's data sources or security
model. Test builds carry "-test.N" and are never published. The build code
comes from the page's code alone, so the hourly data never changes it.

1.1.8 (Nov 1, 2026)
  - Giveaway prize pool: the total refreshes the moment the page connects
    to the network, instead of showing the hourly index's older balance for
    the first minute (it read 50 BRC after 951.1337 BRC had arrived). Until
    every block is counted it now says "as of block N, catching up".

1.1.7 (Oct 31, 2026)
  - Release postmark for BRC Vault 1.1.2 (block 93,335), the first signed
    after the giveaway launch under the published-release-postmark rule.

1.1.6 (Oct 31, 2026)
  - The block 100,000 giveaway goes live: launch signed on the chain by the
    BRC Works release address in block 93,319; 1,280 eligible addresses
    (block 93,000); entries open as soon as the launch is settled, close
    Nov 11 23:59:59 UTC; draw Nov 13 18:00 UTC (drand round 33,929,812).
  - Release postmarks for BRC Vault 1.1.0 (block 93,303), 1.1.1 (93,312) and
    BRC Post 0.6.1 (93,315): Check it now says which BRC Works files are
    genuine.
  - Between launch and draw the release address may also sign release
    postmarks published on Pulse (each provably a release, never a list);
    any other lock still blocks the winner. So BRC Works can keep shipping.
  - An address cut short (or with extra characters) when copying is
    explained instead of "couldn't be recognised".

  - Security review before release: a verdict now always belongs to the
    exact text it was made from (editing the box drops it and any re-check);
    a genuine release message pasted with a different file says "This file
    isn't …", never "Genuine"; look-alike signers are refused on the chain
    path too; more secret-key formats are caught; no "write back" from a bare
    signature (its signer may not be a mailbox).
  - BRC Post is in the family switcher, footer and BRC Works section.
  - test.1 (was 1.1.4-test.1): Check it, rebuilt after an "it just works" review. "Is it real?
    Check it." One box takes anything: a postmark receipt, a message signed
    on the chain or with a BRC Post mailbox, a sealed letter, a mailbox link,
    an address (spaces and capitals fine), or a file on its own (is it a BRC
    Works release?). It says what it recognised, checks at once on paste,
    and answers in one plain verdict ("Real. Made between 2:35 and 2:55 PM
    UTC on Oct 30, 2026.") with the evidence behind Details. A postmark not
    found is "Not on the chain yet" and is looked for again at every new
    block; a matching file is never shown green before the postmark is
    found. Wallet files and recovery words pasted by mistake are cleared.
    #check=<text> links (from BRC Post) check straight away. The block timer
    and new-block toasts stay off this view; the drand/recent-block helpers
    for hand-made postmarks moved to a closed section that loads only when
    opened. Check it and Giveaway come first in the tab bar, so they show on
    a phone. MY BRC takes addresses in groups of 8, capitals or inside a
    link, and a bad address clears the old result.
  - Giveaway: who can enter is said up front ("Open to the 1,280 addresses
    that held 50 BRC or more…"); the rules are plain, with the proof behind
    "How it's fair (details)"; the rules fit a phone; waiting for the chain
    to confirm the rules reads as a wait, not an error, and "The rules are
    confirmed on the chain" shows when they are.
  - Includes 1.1.3-test.1: BRC Seal is now BRC Post in every mention.

1.1.3 (Oct 31, 2026)
  - MY BRC: blocks you find now show in Activity ("Found a block", +reward),
    newest first with your payments. Before, they were only counted under
    Mining, so a block found an hour ago seemed missing (Patrick, Oct 31).

1.1.2 (Oct 31, 2026)
  - The BRC Works addresses' balances are read again on every new block while
    Check it is open. Before, they were read once when the page opened, so a
    payment made after the page's built-in data was missed until a reload
    (found when the release address was funded in block 93,208).

1.1.1 (Oct 31, 2026)
  - The BRC Works addresses (release address, giveaway mailbox, prize pool)
    are listed under Check it with what each holds, and look-alikes of them
    are flagged across Pulse.

1.1.0 (Oct 31, 2026)
  - Release: "Is this BRC Works file genuine?" stays hidden until the first
    release is postmarked, instead of calling every file unreleased.
  - test.4: the three buttons under the headline are now matching tiles (same
    size, icon, title, one line of text, arrow), side by side on wide screens
    and full-width rows on phones; the giveaway has its own gift icon. The big
    block timer now uses the Pulse mark with the BRC PULSE wordmark under it.
  - test.3: BRC Seal's shared code (vendor/brc-kit.js) updated so its messages
    point to "Check it" too.
  - test.2: "Check it" is now part of the dashboard, not a separate page
    tacked on. The view is built from the same cards as the rest of Pulse
    (check a postmark or signature, is this file genuine, BRC Works
    addresses); the home page links to it from the top and from a BRC Works
    band that replaces the old Vault box; the drand and recent-block helpers
    for making a postmark fold away. On narrow screens the section links
    become a scrolling strip instead of disappearing, so Check it and the
    giveaway are one tap away on phones.
  - Fixes from the Fable 5.1 security review (Oct 31): helper data must be
    hex or it is dropped; no giveaway winner unless the list and draw round
    were fixed on the chain by the release address 30+ minutes before the
    draw; release postmarks carry their block; only a signer's own lock
    counts; address picture from SHA-256.
  - Check a stamp: verify BRC Seal postmark receipts against the chain, with
    an optional Lock ID and a drand "made after" beacon checked in the page.
  - The block 100,000 giveaway: address-only entries sealed in the page and
    dropped in the BRC Mailbox, the prize pool, the published lists and their
    fingerprints, and the drand draw, all checked in the page.
  - Messages signed on the chain in BRC Seal, and mailbox links, are checked
    in Check a stamp. A copy locked by another address is refused.
  - Is this BRC Works file genuine? A file is fingerprinted in the page and
    matched to a release signed on the chain by the BRC Works release address.
  - BRC Works addresses, with live balances, on the Stamps view. Addresses
    imitating any named address are marked as look-alikes.
  - The version and build code are shown in the footer.

1.0.0
  - Live network stats, history since launch, My BRC address pages.
